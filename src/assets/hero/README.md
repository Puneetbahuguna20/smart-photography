# Hero Category Images

Har category folder me sirf **1 photo** daalni hai:
- `wedding/`
- `pre-wedding/`
- `haldi/`
- `mehendi/`
- `birthday/`
- `baby-shoot/`
- `fashion/`

### Rules:
1. **Ek hi image**: Alag se `hero` ya `thumb` rakhne ki zaroorat nahi hai. Wahi 1 image Hero Background aur Thumbnail dono jagah automatically dikhegi.
2. **Image ka naam kuch bhi ho sakta hai**: Jaise `IMG_1024.jpg`, `photo.png`, `wedding.webp`, etc.
3. **Automatic Detection**: Jaise hi aap image folder me daalenge, website automatically use pick kar legi.
